A cinematic 3D Mission Control website built for **Muhammad Shariq Khan**. Instead of static pages, visitors enter a single continuous WebGL environment where camera motion, floating 3D artifacts, particle streams, and atmospheric glow tell the story.

---

## 🎨 Visual Experience & Features

* **Continuous 3D Environment**: One seamless WebGL world with camera flight along a 3D spline path.
* **Holographic Identity Core**: Rotating torus wireframes, floating geometric meshes, and radar grid visuals.
* **Orbital Mission Sectors**: 5 interactive 3D nodes representing AI, Cybersecurity, Space, Aviation, and Software Engineering with hover glow effects.
* **3D Project Pods**: Floating wireframe project modules with real-time category filtering and direct GitHub links.
* **Skill Network Graph**: Connected 3D nodes illustrating relationships across languages, frameworks, and AI tools.
* **Journey & Mission Log**: Camera path through glowing year markers (2021 to 2026).
* **Orbital Earth & Satellites**: Rotating wireframe globe with satellite trajectories.
* **Futuristic HUD Overlay**: Minimalist glassmorphic telemetry with live clock and zone navigation dots.
* **Cinematic Post-Processing**: Selective Bloom glow and Vignette pipeline.

---

## 🛠️ Built With

* **Core**: React 19, Vite 8, JavaScript
* **3D & Graphics**: Three.js, React Three Fiber, Drei, Postprocessing
* **Motion & Scroll**: GSAP, Lenis Smooth Scroll
* **Styling**: Glassmorphism, Custom WebGL Scrollbars, Outfit & JetBrains Mono Fonts

## 🚀 Quick Setup & Deployment

```bash
# Clone repository
git clone https://github.com/shariqkhan256/portfolio.git
cd portfolio

# Install dependencies
npm install

# Run dev server
npm run dev

# Deploy to GitHub Pages (free)
npm run deploy
```
